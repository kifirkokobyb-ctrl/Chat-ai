# SmolLM2 Android PWA — загрузчик модели внутри приложения

Мобильный PWA-чат на WebLLM с загрузчиком публичного Hugging Face Bucket.

## Что умеет

- Самостоятельно получает список файлов из публичного Bucket `Skilbanan/SmolLM2-360M-Instruct-q0f16-MLC-bucket`.
- Скачивает файлы модели по одному с индикатором прогресса.
- Сохраняет файлы в Cache Storage браузера под локальными URL.
- Service Worker отдаёт сохранённые файлы WebLLM без интернета.
- После загрузки кнопка «Начать общение» запускает локальную модель.

## Важные ограничения

1. Это PWA, не APK. Для установки на Android приложение должно быть открыто с HTTPS-сайта (или localhost). Обычный `file://` не поддерживает Service Worker.
2. Архив — исходники приложения. Чтобы оно появилось как устанавливаемый сайт, его нужно один раз разместить на HTTPS-хостинге. Сам ChatGPT не может опубликовать сайт в твоём аккаунте.
3. Первый запуск и скачивание модели требуют интернета. После скачивания приложение можно открыть без сети, если Chrome сохранил кэш.
4. Размер модели зависит от фактического содержимого Bucket. Освободи достаточно места на телефоне и не очищай данные сайта.
5. WebGPU и `shader-f16` поддерживаются не всеми Android-устройствами. Даже если PWA установилась, модель может не запуститься на конкретном GPU.
6. Hugging Face должен разрешать публичный доступ к списку и скачиванию Bucket. Если браузер заблокирует запрос из-за CORS, загрузчик покажет ошибку; тогда потребуется небольшой HTTPS-прокси, который не требует секретов для публичного Bucket.

## Подготовка и запуск

Нужны Node.js 20+ и npm:

```bash
npm install
npm run build
npm run preview
```

Для тестирования на том же устройстве открой localhost, если сервер запущен на телефоне. Для установки PWA с другого устройства или постоянного использования разверни содержимое `dist/` на HTTPS-хостинге.

## Источник файлов

Публичный bucket:
`https://huggingface.co/buckets/Skilbanan/SmolLM2-360M-Instruct-q0f16-MLC-bucket`

Bucket API для списка файлов:
`https://huggingface.co/api/buckets/Skilbanan/SmolLM2-360M-Instruct-q0f16-MLC-bucket/tree?recursive=true`

Файлы модели берутся из `/buckets/{namespace}/{bucket}/resolve/{path}`. WebGPU-библиотека, если её нет в Bucket, берётся из официального бинарного набора MLC WebLLM 0.2.87.

## Проверка

- На HTTPS открой сайт в Chrome Android.
- Нажми «Скачать SmolLM2» и дождись 100%.
- Нажми «Начать общение» и дождись статуса «Готова к работе».
- Закрой вкладку, включи авиарежим и открой установленную PWA снова.
